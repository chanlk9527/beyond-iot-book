# 物模型定义与支持范围

物模型包含属性 `properties`、功能 `operations`、事件 `events`。三类能力及功能输入、事件字段均支持 `id`、`name`（100 字符）、`description`（1000 字符）。标识符必须以英文字母开头，只包含字母、数字、下划线，最长 64 字符；对象键必须与定义 id 一致。名称和说明允许缺省，以兼容已发布的历史模型。

## 数据类型

| 类型 | JSON 传输值 | 约束 |
| --- | --- | --- |
| BOOLEAN | 布尔值 | true / false |
| INTEGER | 整数 | minimum / maximum，整数边界 |
| DECIMAL | 数值 | minimum / maximum，后端精确小数校验 |
| TEXT | 字符串 | maxLength，后端按 Unicode 码点计数 |
| ENUM | 字符串 | enumValues 为“值 → 显示名称”，1～100 项，未定义的值拒绝 |
| ARRAY | JSON 数组 | items 指定统一元素类型，minItems / maxItems 限制项数（0～1000），不支持嵌套数组 |

INTEGER、DECIMAL 可以配置 `unit`（最多 32 字符）。单位只描述数值含义，不自动换算。枚举编码即使写为 `"1"`，也必须上报字符串 `"1"`，数值 `1` 不会被自动转换。枚举编码最长 64 字符，显示名称最长 100 字符，两者均不能为空白。

```json
{
  "properties": {
    "mode": {
      "id": "mode",
      "name": "工作模式",
      "description": "设备当前运行模式",
      "access": "READ_WRITE",
      "schema": {"type": "ENUM", "enumValues": {"off": "关闭", "heat": "加热", "warm": "保温"}}
    },
    "samples": {
      "id": "samples", "name": "温度采样", "access": "READ_ONLY",
      "schema": {"type": "ARRAY", "items": {"type": "DECIMAL", "unit": "℃"}, "minItems": 1, "maxItems": 20}
    }
  },
  "operations": {},
  "events": {}
}
```

功能的 `inputs`、事件的 `fields` 都是字段定义映射，字段包含 `id`、`name`、`description`、`schema`、`required`。空参数功能和空字段事件合法；必填参数缺失、未知字段、类型或约束不符均被后端拒绝。属性支持只读、只写、读写访问控制。枚举使用字符串、数组使用原生 JSON 数组消息格式，可用于属性上报、事件字段、指令参数和期望状态。

## 编辑、发布与兼容

可视化编辑支持名称/标识搜索、参数名称说明、枚举选项、数组元素及项数约束和数值单位；切换类型清除不适用约束。枚举逐行填写“枚举值”和“显示名称”，提供添加、删除按钮及选项计数；空值和重复值会直接提示且不能应用到草稿。JSON 编辑使用同一后端模型校验。保存只更新草稿，发布生成不可变版本；设备继续使用登记时绑定的模型版本。新增元数据纳入版本差异。历史 JSON 缺失元数据、单位和枚举选项时读取为兼容默认值，无需迁移数据库。

## 后续缺口

- 结构体与嵌套数组暂不支持，其他新类型须先与用户确认。
- 功能输出参数与同步/异步调用模式：需要扩展设备回复协议及关联、超时处理，当前仍使用既有执行结果协议。
- 事件级别、布尔值显示文案、数值步长/精度、默认值和正则：可进一步补充；当前不会自动填入缺失的必填参数。
- 模型版本兼容性分级与设备迁移：现有版本差异只展示新增、修改、删除，不自动迁移绑定设备。
