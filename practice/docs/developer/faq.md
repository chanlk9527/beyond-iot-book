# 常见问题与排查

## 为什么看不到“我的应用”？

应用管理需要登录，且账号是有效租户的 OWNER 或 ADMIN。普通成员可以阅读公开资料，但无权申请应用或获取凭证。平台超管使用管理平台中的“开放平台管理”审核申请。

## 应用获批后能操作所有设备吗？

不能。scope 只表示允许使用的能力类型，设备访问还需要资源授权。设备绑定和资源授权尚未完整接入当前开放接口。

## 为什么令牌返回 401？

先检查应用是否获批、应用与租户是否启用、密钥是否已经轮换，以及令牌是否过期或撤销。当前令牌有效期为 30 分钟，过期后用应用密钥重新申请。不要无限重试。

## 为什么提交申请或审核时返回 409？

可能是页面中的 revision 已过期，或者当前状态不允许操作。例如待审核的申请不能重复提交。刷新列表，确认状态后再操作。

## 密钥对话框关闭后还能找回吗？

不能。再次获取会生成新密钥，并使旧令牌在后续请求中失效。将密钥保存到服务端密钥配置，不要放入网页、App 或代码仓库。

## 设备能连接，但应用看不到设备，是同一个问题吗？

设备认证、应用认证和资源授权是不同环节。先核对设备在线状态，再检查应用身份、租户归属和资源权限。应用通过身份接口验证，不代表业务设备接口已经开放。

## 能直接使用标准 OAuth 客户端吗？

当前令牌接口采用项目自定义 JSON 协议，尚未完整兼容 OAuth 2.0。请求格式以 [OpenAPI 文档](../openapi/README.md) 为准。

## 开发者中心会提供在线调试吗？

第一版提供文档、接口定义下载和可运行示例。在线执行 API、设备消息调试和 SDK 下载后续再建设；当前不提供空壳调试入口。
